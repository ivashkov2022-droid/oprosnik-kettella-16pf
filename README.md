# 16-факторный личностный опросник Кеттелла — 16PF

Отдельный веб-проект для прохождения русскоязычной формы A и получения профиля по 16 первичным личностным факторам.

## Как работает

- 187 вопросов с тремя вариантами ответа;
- отдельные формулировки мужской и женской формы;
- автоматическое сохранение незавершённого прохождения на устройстве;
- подсчёт сырых баллов по ключу 16 шкал;
- перевод результатов в стены 1–10 с учётом пола и возрастной группы;
- локальная история завершённых профилей с отдельным удалением записей;
- ответы и результаты не отправляются на сервер.

Результат предназначен для ориентирующего знакомства с личностным профилем, не является диагнозом и не заменяет профессиональную психодиагностику.

## Источники рабочей реализации

- банк вопросов: psytests.org, форма A;
- ключ первичных факторов и нормативные таблицы: Psylist;
- прямые баллы ответов сверены с опубликованными методическими материалами.

## Локальный запуск

```bash
npm install
npm run dev
```

После публикации публичная версия может автоматически разворачиваться через GitHub Pages.
